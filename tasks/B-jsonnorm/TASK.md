# B. Нормализация строк в JSON-файле

- **Ветка:** `task/b-jsonnorm`
- **Зависимости:** A — используется `textkit.normalize_text`. Стартует только после merge PR задачи A в `main`; локальный коммит или открытый PR не считаются.

## Цель

Команда `python -m textkit.jsonnorm INPUT [-o OUTPUT]`. Она читает JSON-файл, нормализует все строковые значения функцией `normalize_text` и пишет результат как JSON.

## Требования

1. Нормализуются строковые значения на любой глубине вложенности, в объектах и массивах. Числа, `true`, `false` и `null` не меняются.
2. Ключи объектов не меняются, порядок ключей сохраняется.
3. Вывод в UTF-8 с `ensure_ascii=False` и отступом 2 пробела. Без `-o` результат печатается в stdout.
4. Если файл не найден или JSON невалиден — понятное сообщение в stderr и код выхода 1, без трейсбека. Ошибки аргументов — код 2, как у argparse по умолчанию.

## Владение файлами

- `textkit/jsonnorm.py` — новый файл
- `tests/test_jsonnorm.py` — новый файл

`textkit/normalize.py` не менять. Если там нужна правка — это вопрос к Galaxy.

## Приёмка

- Тесты в `tests/test_jsonnorm.py` проверяют каждое требование. Поведение команды проверяется запуском `sys.executable -m textkit.jsonnorm` через `subprocess`.
- `python -m unittest discover -s tests -v` проходит.
- `ruff check .` и `ruff format --check .` проходят.
- В HANDOFF — команды, коды выхода и вывод тестов и линтера.

## Вне scope

Потоковая обработка больших файлов, нормализация ключей, другие форматы кроме JSON.
